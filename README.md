# ⚔️ 성장형 오경호 : 고2 178cm 각성 프로젝트 (1:1 맞다이 극악 보스 레이드)

> **"고등학교 2학년, 키 173cm에서 178cm로의 현실적 기적!"**  
> **"보스 한 개 한 개마다 한 달(30일) 동안 매일매일 빠짐없이 수련해야 아슬아슬하게 깰까 말까 한 극한의 난이도!"**  
> 복잡한 조작 없이 오직 **공격 버튼 단 하나! [나 한 대 때리고, 보스 한 대 맞고]** 서로 피 튀기는 1:1 진검승부 맞다이 액션 RPG입니다.

## 🌟 핵심 시스템 & 최신 개편 내역

### 1. ⚔️ 공격 버튼 딱 1개! [나 한 대, 보스 한 대] 1:1 진검 맞다이 전투
- 복잡한 4방향 회피나 다중 스킬 버튼을 전면 배제하고, **오직 단 하나의 공격 버튼(`[💥 결전의 일격 가하기]`)**으로 진행되는 초긴장감 1:1 턴제 공방전입니다.
- **공방 흐름**:
  1. **플레이어 전력 일격**: 플레이어가 보스를 향해 검/펀치를 내리꽂아 묵직한 타격(사운드, 화면 흔들림, 보스 피격 반동)을 가합니다.
  2. **보스 치명적 반격**: 플레이어의 공격 직후 0.5초의 긴장감 후, 보스가 포효하며 화면을 향해 돌진해 플레이어에게 무자비한 반격을 가합니다(화면 적색 점멸, 중장타 사운드).
  3. **목숨을 건 맞다이**: 서로 1대씩 주고받으며, 한 달간의 수련이 부족하면 단 2~3턴 만에 즉사합니다!

### 2. 🔥 보스 1단계마다 "1달간 매일 수련해야 아슬아슬하게 클리어"하는 극악 밸런스
- **Stage 1 (나태의 망령, 슬로스)**:
  - 체력 `3,200` / 공격력 `410` / 방어력 `70`
  - **1일차 플레이어(Lv.1, 체력 700)**가 도전할 경우:
    - 내 공격력으로는 보스에게 고작 15~25 대미지밖에 안 들어감
    - 보스의 반격 1방에 **370+ 피해**를 입고 단 **2턴 만에 즉사(K.O.)**!
  - **30일간 매일 일일퀘스트를 완수한 플레이어(Lv.15, 체력 ~2,700, 방어력 ~140)**가 도전할 경우:
    - 보스의 반격을 버텨내며 10~11턴 동안 혈투 끝에 **피 1줄(100~200 HP) 남기고 아슬아슬하게 승리**하는 극한의 쾌감!
- **Stage 2 (숏폼의 환영귀, 스크롤러)**: 2달(60일) 수련 필수
- **Stage 3 (야식의 폭식마, 글러튼)**: 3달(90일) 수련 필수
- ...
- **Stage 50 (최종 보스: 크로노스)**: 총 50개월의 끈질긴 자기관리와 키 성장의 결정체!

### 3. 🤝 일일 퀘스트 완료 시 "자신과의 정직한 약속" 서약 모달
- 퀘스트 목록에서 `[완료 인증]` 클릭 시:
  > **🤝 자신과의 정직한 약속**  
  > *"정말로 오늘 이 수련을 정직하게 완수하셨습니까? 거짓된 완료는 당신의 실제 신체와 키를 성장시키지 못합니다. 자신을 속이지 않는 진정한 각성자만이 178cm에 도달할 수 있습니다."*
  > ➔ 정직하게 수련한 경우에만 완료하여 보상을 수령합니다.

### 4. 📏 현실적인 키 성장 공식 (173.00cm ➔ 178.00cm)
- **현재 신장**: `173.00 cm` (고2 수험생 각성자)
- **목표 신장**: `178.00 cm` (+5.00 cm = 50.0 mm)
- **공식**:
  - `1,000 pt = 0.1 cm (1.0 mm)`
  - 총 `50,000 pt`를 수개월에 걸쳐 모아야 178.00 cm에 도달!
  - 퀘스트 1개당 `5 ~ 25 pt` (`+0.005 ~ +0.025 cm`)가 정밀하게 소수점 둘째 자리까지 누적됩니다.

### 5. ✏️ 프로필 & 신장 수정 기능
- 상태창의 `[✏️ 프로필 & 현재 키 / 목표 키 수정]` 버튼을 통해 닉네임, 현재 키, 목표 키를 언제든 자유롭게 수정할 수 있습니다.
