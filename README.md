# ⚔️ 각성한 헌터 : 성장형 액션 RPG (Awakened Hunter RPG)

> **"매일의 정직한 현실 수련을 캐릭터의 압도적인 스펙으로!"**  
> **"보스 한 개 한 개마다 한 달(30일) 동안 매일매일 빠짐없이 수련해야 아슬아슬하게 깰까 말까 한 극한의 난이도!"**  
> 복잡한 조작 없이 오직 **공격 버튼 단 하나! [나 한 대 때리고, 보스 한 대 맞고]** 서로 피 튀기는 1:1 진검승부 맞다이 액션 RPG입니다.

## 🌟 핵심 시스템 & 기능 안내

### 1. 🛡️ 진행 상황 영구 보존 & 절대 손실 방지 (2중 미러링 + 백업 복원)
- **실시간 자동 저장**: 퀘스트 완료, 스탯 투자, 보스 클리어 등 모든 행동 시 즉시 브라우저에 저장됩니다.
- **2중 미러링 안전장치**: 메인 저장소(`awakened_hunter_save_v2`)와 비상 미러 저장소(`awakened_hunter_save_mirror_v2`)에 동시 기록되어, 브라우저 캐시 삭제 시에도 자동 복구됩니다.
- **페이지 이탈 안전 훅**: 브라우저를 닫거나(`beforeunload`), 백그라운드로 전환(`visibilitychange`), 화면을 끌 때(`pagehide`) 즉각 강제 저장됩니다.
- **수동 백업 & 기기 이동 (설정 탭)**:
  - `[📥 세이브 파일(JSON) 다운로드]`: 폰에서 PC로, 혹은 새 폰으로 바꿀 때 세이브 파일로 간편 저장
  - `[📋 세이브 텍스트 코드 복사]`: 카카오톡 '나에게 보내기'나 메모장에 텍스트로 보관 가능한 암호화 코드
  - `[📁 JSON 파일 불러오기]` & `[📝 텍스트 코드 입력 복원]`: 언제든 이전 기록을 1초 만에 완벽 복구!

### 2. 📱 모바일 전용 UI & 오류 없는 편의성
- **하단 고정 내비게이션 바**: 한 손으로 편하게 `상태창`, `퀘스트`, `50보스`, `인벤토리`, `설정` 5대 메뉴 이동.
- **전투 몰입 모드 (`body.in-battle`)**: 결전 시작 시 헤더와 하단 바가 자동으로 숨겨지며 스마트폰 한 화면에 보스, 내 캐릭터, 대형 단일 공격 버튼이 깔끔하게 표시됩니다.
- **터치 딜레이 & 자동 확대 방지**: 모바일 입력 포커스 시 화면이 튀지 않도록 폰트 규격 및 `touch-action: manipulation` 최적화.

### 3. ⚔️ 공격 버튼 딱 1개! [나 한 대, 보스 한 대] 1:1 진검 맞다이 전투
- 복잡한 4방향 회피나 다중 스킬 버튼을 전면 배제하고, **오직 단 하나의 공격 버튼(`[💥 결전의 일격 가하기]`)**으로 진행되는 초긴장감 1:1 턴제 공방전입니다.
- **공방 흐름**:
  1. **플레이어 전력 일격**: 플레이어가 보스를 향해 검/펀치를 내리꽂아 묵직한 타격(사운드, 화면 흔들림, 보스 피격 반동)을 가합니다.
  2. **보스 치명적 반격**: 플레이어의 공격 직후 0.42초 뒤, 보스가 포효하며 무자비한 반격을 가합니다(화면 적색 점멸, 중장타 사운드).
  3. **목숨을 건 맞다이**: 서로 1대씩 주고받으며, 한 달간의 수련이 부족하면 단 2~3턴 만에 즉사합니다!

### 4. 👑 찐막 최종보스 : [제51의 벽 - 절대 거신, 오메가 크로노스]
- 50단계 보스를 모두 정복한 진정한 수련자에게 개방되는 전설의 신화 거신!
- **체력 `999,999` / 공격력 `8,888` / 방어력 `3,500`**의 초극악 난이도.
- 결전의 전당 입장 시 웅장한 신화 팡파르 BGM과 코스믹 천둥 진동 효과 발동.

### 5. 🔥 보스 1단계마다 "1달간 매일 수련해야 아슬아슬하게 클리어"하는 극악 밸런스
- **Stage 1 (나태의 망령, 슬로스)**: 체력 `3,200` / 공격력 `410` / 방어력 `70`
- 1일차 플레이어(Lv.1, 체력 700)가 도전할 경우 보스 반격 1방에 370+ 피해를 입고 2턴 만에 즉사!
- 30일간 매일 수련한 플레이어(Lv.15, 체력 ~2,700, 방어력 ~140)만이 혈투 끝에 아슬아슬하게 승리합니다.

### 6. 🤝 일일 퀘스트 완료 시 "자신과의 정직한 약속" 서약 모달
- 퀘스트 목록에서 `[완료 인증]` 클릭 시 정직하게 수련했는지 확인하는 서약 창이 나타나 진정한 자기 관리를 유도합니다.

### 7. 📏 정밀한 키 성장 공식 시스템
- `1,000 pt = 0.1 cm (1.0 mm)`
- 일일 현실 수련 퀘스트를 수행하여 목표 신장을 향해 꾸준히 성장하도록 정밀 설계되었습니다.

## 🎮 조작법 (초간단 & 직관적)

### 💻 PC
- `Space`, `Enter`, 또는 화면의 **[💥 결전의 일격 가하기]** 버튼 클릭
- 한 번 누르면 나 한 대 때리고, 보스 한 대 맞고 다음 턴으로 전환!

### 📱 모바일
- 화면 하단의 큼직한 **[💥 결전의 일격 가하기]** 버튼 터치
- 모바일 화면에서도 보스와 내 체력, 피해 예측치가 한눈에 쏙 들어오도록 최적화 완료!
